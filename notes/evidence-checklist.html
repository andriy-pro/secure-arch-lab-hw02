Рекомендації для наступних скриншотів

  1. У кожному скриншоті має бути видно URL або endpoint, HTTP method, status code і ключовий фрагмент JSON-відповіді.
  2. Не показувати повний JWT у фінальних скриншотах; достатньо показати, що токен належить звичайному користувачу або що роль у payload не є admin.
  3. Для IDOR/BOLA краще показати поруч або в описі: який користувач увійшов, який basket ID запитувався, і який UserId повернувся у відповіді.
  4. Для SQLi краще мати поруч контрольний пошук apple і ін'єкційний запит q='))--, щоб було видно різницю у формі відповіді.
  5. Для Mass Assignment показати саме варіант з role: "admin", бо варіант з isAdmin: true не підтвердив ескалацію в цій локальній перевірці.
